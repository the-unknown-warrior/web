Texting that never touches the internet.

Messages sends and receives SMS and MMS straight over your carrier — no cloud relay, no account to sign into, nothing syncing your conversations anywhere else. It runs entirely offline, so what's in a thread stays between the phones sending it.

The idea

A text is just a text — it shouldn't need a server.

Plenty of messaging apps route ordinary texts through company servers, or hold onto delivery metadata even when the message itself is a plain SMS. Messages doesn't have a server to route through — it talks to your carrier's SMS and MMS network directly, the same way texting has worked for two decades, and nothing about that requires a cloud account.

Like Phone, it's built to run completely offline. No sign-in, no background sync, no message content ever leaving the device except over the network already carrying your calls — which is what makes it a real degoogle replacement rather than a different company holding the same data.

How it works

Nothing between you and the message

No account, no relay, no data connection required.

01

Write

Pick a contact — pulled straight from Phone if you're using both — and start a thread the way texting has always worked.

02

Send

Messages go out over SMS or MMS through your carrier directly — no app server in the middle, no data connection needed.

03

Keep

Every thread stays stored on the device, not a cloud backup, so it's there only for as long as you decide to keep it.
